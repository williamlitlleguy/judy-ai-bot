# 🤖 بات جودی (Judy Telegram Bot)

دستیار هوش مصنوعی تلگرام با **حافظه مکالمه**، **حافظه تصویری**، **پشتیبانی از گروه‌ها**، **ساخت عکس با مدل قوی** و **سیستم درخواست آپدیت واقعی** — ساخته شده با ❤️ توسط **ویل** (یک برنامه‌نویس ۱۴ ساله!)

## ✨ امکانات

| امکان | توضیح |
|---|---|
| 💬 چت با هوش مصنوعی | گفتگوی فارسی و صمیمی با مدل GLM |
| 🧠 حافظه مکالمه | بات ۲۰ پیام آخر را به خاطر می‌سپارد (با `/reset` پاک می‌شود) |
| 🎨 ساخت عکس قوی | مدل `glm-image` + تبدیل خودکار توضیح فارسی به پرامپت انگلیسی حرفه‌ای + زنجیره جایگزین (`cogview-4` ← پیش‌فرض) |
| 👀 دیدن عکس | با مدل بینایی `glm-4.5v` عکس را توصیف می‌کند |
| 🧠 حافظه تصویری | عکس‌هایی که می‌فرستی با توصیف ذخیره می‌شوند و `/photos` دوباره نشانشان می‌دهد |
| 👑 هویت سازنده | فقط آیدی تأییدشده‌ی ویل «ویل» نامیده می‌شود؛ بقیه با اسم خودشان |
| 👥 پشتیبانی از گروه‌ها | بات را به گروه اضافه کن — به منشن، ریپلای و صدازدن «جودی» جواب می‌دهد و هر گروه حافظه‌ی خودش را دارد |
| 🚀 درخواست آپدیت واقعی | `/update` (برای همه!) درخواست را در صف ثبت می‌کند و ایجنت سازنده واقعاً اجرا می‌کند |
| 📁 ذخیره فایل | عکس، ویدیو، سند، صدا بفرست — ذخیره می‌شود و هر وقت خواستی پس می‌گیری |
| 📊 آمار کاربران | تعداد پیام‌ها، عکس‌ها، فایل‌ها و تاریخ عضویت با `/stats` |
| ⌨️ منوی شیشه‌ای | منوی Inline حرفه‌ای زیر پیام خوش‌آمد |
| 👋 پیام خوش‌آمد | با عکس اختصاصی تولیدشده با هوش مصنوعی |
| 🐙 انتشار گیت‌هاب | دستور `/publish` با تایید دو مرحله‌ای (بله/نه) |

## ⌨️ دستورات

```
/start   — شروع بات و منوی اصلی
/help    — راهنمای کامل
/img     — ساخت عکس با مدل قوی (مثلاً /img یه ربات فضانورد)
/about   — درباره بات
/stats   — آمار من
/files   — لیست فایل‌های ذخیره‌شده
/photos  — حافظه تصویری (عکس‌هایی که دیده‌ام)
/memory  — خروجی حافظه برای ایجنت‌های دیگر
/reset   — پاک کردن حافظه مکالمه
/id      — نمایش آیدی عددی
/update  — درخواست آپدیت واقعی (برای همه!)
/publish — انتشار کد در گیت‌هاب (با تایید)
```

## 👥 جودی در گروه‌ها

**فقط ویل (سازنده)** می‌تواند جودی را به گروه اضافه کند — اگر کس دیگری امتحان کند، جودی پیام محترمانه می‌دهد، از گروه خارج می‌شود و به ویل گزارش امنیتی می‌فرستد! 🔐

کافیست جودی را با اکانت ویل به گروه اضافه کنی (Add Member). او خودش را معرفی می‌کند و:

- به **منشن** جواب می‌دهد: `@Glmagentdamnbot سلام`
- به **ریپلای** روی پیام‌هایش جواب می‌دهد
- وقتی کسی اسمش را صدا بزند: «جودی فلان چیه؟»
- دستورات (`/img`، `/help` و...) در گروه هم کار می‌کنند
- گاهی خودش هم به بحث سرک می‌کشد 😄
- هر گروه **حافظه‌ی جداگانه** دارد

> 💡 برای اینکه جودی **همه‌ی** پیام‌های گروه را ببیند، در BotFather: پروفایل بات ← Bot Settings ← Group Privacy ← **Turn off**. سپس بات را یک بار از گروه خارج و دوباره اضافه کن.

متغیرهای محیطی:

```
BOT_TOKEN=توکن بات از BotFather
BOT_OWNER_ID=آیدی عددی سازنده (دسترسی ادمین)
```

## 🚀 راه‌اندازی

### پیش‌نیازها
- Node.js نسخه ۱۸ یا بالاتر
- یک توکن بات از [@BotFather](https://t.me/BotFather)

### مراحل

```bash
# 1. نصب پکیج‌ها
npm install

# 2. ساخت فایل .env و گذاشتن توکن داخلش
echo "BOT_TOKEN=توکن_بات_شما" > .env

# 3. اجرا!
npm start
```

بات با **Long Polling** کار می‌کند؛ یعنی نیازی به دامنه، سرور یا SSL ندارد و روی هر سیستمی که اینترنت داشته باشد اجرا می‌شود.

## 📦 استقرار (Deployment)

برای اجرای دائمی می‌توانی از این سرویس‌ها استفاده کنی:

- **Railway / Render** — رایگان و ساده؛ فقط مخزن را وصل کن و متغیر محیطی `BOT_TOKEN` را ست کن
- **VPS** — با `pm2 start bot.js --name judy-bot` بات را برای همیشه روشن نگه دار

## 🔒 نکات امنیتی مهم

1. **توکن بات هرگز در گیت‌هاب منتشر نشود** — فایل `.env` در `.gitignore` است، پس با خیال راحت ریپو بساز
2. اگر توکنی جایی لو رفت، از BotFather دستور `/revoke` بزن تا توکن جدید بگیری
3. دیتابیس (`data/db.json`) و فایل‌های کاربران (`data/files/`) هم در `.gitignore` هستند
