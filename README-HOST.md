# 🚀 راهنمای انتقال جودی به هاست رایگان

جودی الان یک فایل پکیج آماده داره. این راهنما هر دو روش رایگان رو قدم‌به‌قدم توضیح می‌ده.

|------|------|

## روش ۱: Render.com (پیشنهاد اصلی — حرفه‌ای و پایدار) ⭐

### قدم ۱: بذار روی گیت‌هاب
1. برو [github.com](https://github.com) و اکانت بساز (اگه نداری)
2. یه ریپوی **Private** بساز (مثلاً به اسم `judy-bot`) — حتماً Private!
3. این فایل‌ها رو آپلود کن: `bot.js` و `package.json` و `package-lock.json` و پوشه `assets`
4. ⚠️ فایل‌های `.env` و `.z-ai-config` رو **آپلود نکن** — اینا رو تو گیت‌هاب نمی‌ذاریم!

### قدم ۲: ببرش روی Render
1. برو [render.com](https://render.com) → با اکانت گیت‌هاب لاگین کن
   - 🪄 اگه موقع ثبت‌نام گیتت کرد، با تغییر IP (مثل فیلترشکن) امتحان کن
2. **New +** → **Web Service** → ریپوی `judy-bot` رو انتخاب کن
3. تنظیمات:
   - **Language:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. پایین صفحه **Environment** → این دوتا متغیر رو اضافه کن:
   - `BOT_TOKEN` = توکن باتت (از فایل .env کپی کن)
   - `BOT_OWNER_ID` = `5807801912`
5. **Create Web Service** بزن → لاگ‌ها رو ببین؛ باید بنویسه «بات جودی آنلاین شد!» ✅

### قدم ۳: نذار بخوابه (خیلی مهم!)
سرویس رایگان Render بعد از ۱۵ دقیقه بی‌کاری خواب می‌ره. ولی نگران نباش — من یه وب‌سرور بیدارباش به جودی اضافه کردم! فقط باید یه جایی هر چند دقیقه بهش سر بزنه:
1. برو [cron-job.org](https://cron-job.org) → اکانت رایگان بساز
2. **Create Cronjob** → آدرس رو بذار آدرس رندرت (مثل `https://judy-bot.onrender.com`)
3. زمان‌بندی: **هر ۱۰ دقیقه** → ذخیره
4. تمام! جودی ۲۴ ساعته بیدار می‌مونه 🎉

## روش ۲: Bot-Hosting.net (ساده‌ترین — فقط آپلود!)

این سایت مخصوص هاست باته و پنلش خیلی ساده‌ست:
1. برو [bot-hosting.net](https://bot-hosting.net) → با اکانت **Discord** لاگین کن (اگه نداری بساز)
2. یه سرور رایگان بگیر (Node.js)
3. فایل `judy-bot-host.zip` رو همون‌جا آپلود/Extract کن
   - اینجا چون مستقیم آپلود می‌کنی، `.env` و `.z-ai-config` هم داخل زیپ هستن و همه‌چیز خودکار کار می‌کنه!
4. توی تب Console/Startup مطمئن شو فرمان استارت `npm start` هست
5. Start بزن — تمام! ✅

## ❓ سوالای احتمالی

**مصرف هاست چقدره؟** جودی خیلی سبکه (چند مگ رم) — هاست رایگان کاملاً کافیه.

**اگه هوش مصنوعی جواب نداد چی؟** یعنی `.z-ai-config` جا مونده. این فایل باید دقیقاً کنار `bot.js` باشه (روی Render هم می‌تونی به‌جای فایل، محتواش رو بذاری توی Environment Variables — اسمش `ZAI_CONFIG` نه، باید فایل باشه؛ راحت‌ترش آپلود فایل در پنل هست).

**Privacy Mode گروه‌ها یادت نره:** تو BotFather → `/mybots` → باتت → Bot Settings → Group Privacy → **Turn off** تا جودی توی گروه همه پیام‌ها رو ببینه.

**دیتای کاربرا (حافظه جودی) چیه؟** پوشه `data/db.json` حافظه جودیه. اگه بخوای جودی تو هاست جدید هم همه‌چیز رو یادش باشه، این فایل رو هم ببر با خودت.
